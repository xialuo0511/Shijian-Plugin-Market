# 界面精简与启动优化

Beta.6 依据本轮目标调整界面，保留项目、任务、日程、回顾、课表联动、插件和 MCP 功能。

| 目标 | 修改与验证 |
| --- | --- |
| 精简界面与文案 | 移除首页宣传横幅、侧栏标语、重复新增入口和重复截止事项；课表连接、插件数据、隐私及更新源收进高级区域或菜单。任务搜索、筛选在刷新和切换页面后保留。 |
| 明亮配色 | 主色亮蓝，配合日落黄、紫色、珊瑚色和青色；新用户默认浅色，已有主题选择保留。旧默认项目颜色在展示时映射，不改写个人记录。 |
| 表格显示 | 周课表采用清晰日期列、蓝色今天和浅黄色周末；课程使用多色卡片，重叠分栏，时间不换行。任务进度与数量对齐，窄窗口分区自动纵向排列，保留全天滚动。 |
| 动效 | 页面淡入、轻位移、按钮按压和进度过渡；系统减少动画时减少空间位移，应用开关关闭全部过渡。原生合成器已完成 11 次页面动画，关闭后无新增过渡。 |
| 启动速度 | 数据读取与窗口创建重叠，扩展服务延迟创建，去除重复首页构建；通知在界面显示后初始化，快速关闭仍会完成提醒登记。 |
| 亚克力透明度 | 原生 DesktopAcrylicController 的 Thin 模式，TintOpacity=0.12，LuminosityOpacity=0.35，卡片改为半透明。浅色/深色实际控制器连接和参数均读取验证；系统不支持时回退纯色。 |

本机同配置 Release 暖启动交替测试 3 组：进程到首帧中位数约 758 ms → 626 ms，约减少 17%；这是本机样本，不是冷启动或其他电脑的保证。后台提醒在首帧之后完成初始化，未通过关闭提醒来提高首帧速度。

验证使用 `.local/ui-refresh` 独立数据。涵盖 12 个宽窄、深浅页面渲染，任务新增、完成、搜索保留、动效开关和材质切换；既有 19 项核心与 21 项集成检查通过。RenderTargetBitmap 的布局图片使用纯色背景占位，不包含 DWM；亚克力参数来自实际连接的系统控制器，图片不作为桌面透视效果的证明。

性能测量仅在 `ShijianStartupProbe=true` 的专用构建中启用。普通发行版不包含启动探针；Debug 界面验证也不进入发行版。

参考：[微软系统背景与自定义控制器](https://learn.microsoft.com/en-us/windows/apps/develop/ui/system-backdrops)。
