# 界面精简与启动优化

## Beta.9

帮助和回收站改为主工作区内的独立页面，跟随侧栏导航与主题。帮助按九类功能组织，使用编号步骤、分类图示、交互示例和“前往功能”；示例只改变展示，不写入学习数据。今天、日程、项目、回顾、课表、扩展、设置及专注卡片提供「？」按钮，在原界面展开提示。

回收站支持搜索、全选当前结果、单项及批量恢复、彻底删除与清空全部；删除在页面内二次确认。搜索变化会清除旧选择。彻底删除按确认时的标识集合执行，拒绝活动或失效任务，原子移除选中任务及其时间块、进度、专注记录，保留其他任务与记录。

手动更新使用同一个对话框：检查时圆形加载，下载及校验时进度条，完成后确认安装重启；错误和重试保留在框内。关闭即取消本次操作，迟到的结果不改写界面；下载完成不会自动安装，便携 ZIP 不自动执行。启动发现新版仍使用角落提醒。

## Beta.8

- 主内容只保留一层圆角边框。修正折叠列仍保留间距的问题，滚动条使用既有留白，中小窗口左右边距一致。大屏仍显示完整七天；较窄窗口明确显示横向滚动条。
- 常驻侧栏透出窗口材质；浮层使用独立 AcrylicBrush，透明度与设置联动，着色遮盖最低 45%，避免后方文字直接叠入菜单。高对比度、纯色与系统效果关闭时回退纯色。手机连接改为默认展开的统一卡片，服务仍手动开启。
- 输入任务名后点添加或按 Enter，先填写详细表单；保存才创建，取消保留草稿。专注时长移至卡片的小按钮，支持预设和 1–180 分钟，活动计时受保护。
- 日/周视图共享压缩后的时间轴，按当前可见安排合并有课时段，长空档压成短条并可展开。Ctrl＋滚轮缩放时保持鼠标所在时刻，最粗 4 小时主刻度；可恢复完整时间轴。缩放直接调整已有元素，尺寸未变时复用网格几何。
- 导入卡片可修改显示名称、指定课程组的名称、地点、提醒与颜色，课程组的各教学周一起更新，保留标识、周规则、节次和实际日期。再次导入会更新同源课次，可能覆盖本地编辑。
- 帮助和回收站为独立侧栏入口；空项目使用文件夹图标。设置显示完整版本号，移除底部标语和专注时长项。隐藏 Root 自动快捷键提示，保留 Ctrl＋N 功能。
- 首帧之后后台检查更新，角落提示可关闭，关闭启动检查后不发起请求；仅检测，不自动下载。Beta／正式版偏好只改变后续更新选择，当前程序版本保持不变，不允许降级。正式版无新发布时继续保留当前版本。

源码未设置 60fps 上限。已减少尺寸变化时的重复赋值、重建及失效页面回调，但尚未测量实际窗口移动时的 DWM 呈现帧率，不能据此宣称纯拖动卡顿已经解决。

## Beta.7

设置 → 外观提供 0–100% 透明度滑杆与数值输入，默认 55%；数值越大越通透。原生 Thin 亚克力的着色及亮度覆盖随数值降低，卡片与表格背景同步变淡，文字保持原有清晰度。预览即时生效，停止调整 500 ms 后保存，关闭应用前补存；保存不重建设置页。此控制仅在系统支持并启用亚克力时可用，高对比度与系统透明关闭仍回退纯色。

日程在新日期范围、日/周视图或来源筛选变化后定位到最早可见时刻；跨午夜条目从当天可见部分计算，空视图从零点开始。同一范围刷新保留手动位置。滚动定位等待原生视口和内容布局就绪，旧页面的回调不覆盖新页面位置。

表头和时间网格重新整理，保留七天及完整 24 小时；今天使用蓝底白字日期标签和整列浅蓝背景，移除单侧高亮边线。课程用学位帽、学习用书本、日常用日历；卡片统一圆角、色条、标题、时间和地点，横向网格线避开卡片，避免从半透明背景中穿过文字。首页日程复用相同卡片，统计区域使用与下方一致的半透明背景，仅保留小块彩色图标；项目、回顾、课表联动、扩展和设置统一标题与容器样式。

## Beta.6

Beta.6 依据本轮目标调整界面，保留项目、任务、日程、回顾、课表联动、插件和 MCP 功能。

| 目标 | 修改与验证 |
| --- | --- |
| 精简界面与文案 | 移除首页宣传横幅、侧栏标语、重复新增入口和重复截止事项；课表连接、插件数据、隐私及更新源收进高级区域或菜单。任务搜索、筛选在刷新和切换页面后保留。 |
| 明亮配色 | 主色亮蓝，配合日落黄、紫色、珊瑚色和青色；新用户默认浅色，已有主题选择保留。旧默认项目颜色在展示时映射，不改写个人记录。 |
| 表格显示 | 周课表采用清晰日期列、蓝色今天和浅黄色周末；课程使用多色卡片，重叠分栏，时间不换行。任务进度与数量对齐，窄窗口分区自动纵向排列，保留全天滚动。 |
| 动效 | 页面淡入、轻位移、按钮按压和进度过渡；系统减少动画时减少空间位移，应用开关关闭全部过渡。原生合成器已完成 11 次页面动画，关闭后无新增过渡。 |
| 启动速度 | 数据读取与窗口创建重叠，扩展服务延迟创建，去除重复首页构建；通知在界面显示后初始化，快速关闭仍会完成提醒登记。 |
| 亚克力透明度 | 原生 DesktopAcrylicController 的 Thin 模式，TintOpacity=0.12，LuminosityOpacity=0.35，卡片改为半透明。浅色/深色实际控制器连接和参数均读取验证；系统不支持时回退纯色。 |

本机同配置 Release 暖启动交替测试 3 组：进程到首帧中位数约 758 ms → 626 ms，约减少 17%；这是本机样本，不是冷启动或其他电脑的保证。后台提醒在首帧之后完成初始化，未通过关闭提醒来提高首帧速度。

验证使用 `.local/ui-refresh` 独立数据。涵盖 12 个宽窄、深浅页面渲染，任务新增、完成、搜索保留、动效开关和材质切换；既有 19 项核心与 21 项集成检查通过。RenderTargetBitmap 的布局图片使用纯色背景占位，不包含 DWM；亚克力参数来自实际连接的系统控制器，图片不作为桌面透视效果的证明。

性能测量仅在 `ShijianStartupProbe=true` 的专用构建中启用。普通发行版不包含启动探针；Debug 界面验证也不进入发行版。

参考：[微软系统背景与自定义控制器](https://learn.microsoft.com/en-us/windows/apps/develop/ui/system-backdrops)。
